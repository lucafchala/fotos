# CLAUDE.md

Leia [`llms.md`](./llms.md) — é lá que fica tudo que uma sessão de agente
precisa saber sobre **ferramentas**: quais tools de GitHub usar e para quê, o
que não existe e por isso não deve ser suposto, e as três camadas de
verificação (local, CI, browser de verdade) que este repositório exige.

Este arquivo não duplica aquele de propósito: uma regra escrita duas vezes é
corrigida uma vez só, e vira a fonte de bug mais cara desta base quando as
duas cópias divergem (ver `TODO.md`, "Regras vivas" → "Uma regra escrita duas
vezes é corrigida uma vez só" — a mesma lição vale para documentação).

Antes de `llms.md`, leia [`RETOMADA.md`](./RETOMADA.md) — descreve o projeto,
onde está cada coisa, e as armadilhas de código já conhecidas. `llms.md`
pressupõe que você já leu aquele.
